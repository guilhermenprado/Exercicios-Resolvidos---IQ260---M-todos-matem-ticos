# IQ260 - Métodos Matemáticos

Repositório acadêmico com exercícios resolvidos da disciplina **IQ260 - Métodos Matemáticos**, do Mestrado em Engenharia Química. Os programas aplicam conceitos de matemática computacional a problemas gerais de engenharia, com foco na compreensão do método, na implementação em Python e na análise dos resultados.

## Objetivo

Registrar a evolução dos estudos e reunir soluções computacionais desenvolvidas ao longo da disciplina. O repositório será atualizado frequentemente com novos exercícios e métodos, mantendo uma visão geral das competências praticadas.

## Principais técnicas praticadas

- Implementação de métodos numéricos para solução de equações não lineares;
- Método de Newton-Raphson;
- Método da secante;
- Uso de derivadas e funções matemáticas na modelagem de problemas;
- Definição de critérios de convergência e cálculo de erros iterativos;
- Estruturação de algoritmos iterativos com acompanhamento das iterações;
- Aplicação de relações matemáticas a problemas de termodinâmica, transferência de calor e escoamento de fluidos;
- Comparação entre valores calculados e dados de referência;
- Geração de gráficos para análise e comunicação dos resultados;
- Uso de bibliotecas Python para computação científica e visualização.

## Competências demonstradas

Este repositório evidencia experiência prática com:

- Raciocínio lógico e decomposição de problemas;
- Tradução de modelos matemáticos em algoritmos;
- Programação científica em Python;
- Análise numérica e interpretação de resultados;
- Validação por comparação com dados tabelados ou referências do problema;
- Organização de soluções por aulas e exercícios;
- Documentação objetiva de um projeto técnico em evolução.

## Organização

Os exercícios estão agrupados por aula.

Novos conteúdos serão adicionados seguindo essa organização conforme o andamento da disciplina.

## Tecnologias

- Python 3;
- NumPy;
- Matplotlib.

## Como executar

1. Instale o Python 3.
2. Instale as dependências necessárias:

   ```bash
   pip install numpy matplotlib
   ```

3. Execute o exercício desejado a partir da pasta do repositório:

   ```bash
   python "Aula 3/061259_Exercicio_2.py"
   ```

O comando e as dependências podem variar conforme os exercícios adicionados ao repositório.
